# Site AMV Patrimônio

Site público publicado em https://www.amvpatrimonio.com.br (GitHub Pages).

**Não edite estes arquivos à mão.** Eles são gerados a partir da pasta de trabalho
`04 Site/` com `04 Site/Publicação/build_site.py`:

1. Edite `04 Site/Site AMV v4.html` (e imagens em `04 Site/Imagens`, vídeo em `04 Site/Videos`).
2. Rode `python -I build_site.py` dentro de `04 Site/Publicação`.
3. Faça commit e push desta pasta.
